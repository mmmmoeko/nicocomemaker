# ニコメメーカー

既存の動画に、ニコニコ動画風のコメントを流し込んだ動画を作るツール。
コメントはスプレッドシートで書いて貼り付け、アプリ上で再生しながら微調整できます。

**ブラウザ版 → https://mmmmoeko.github.io/nicocomemaker/**
インストール不要です。動画もコメントもアップロードされず、すべて手元のブラウザで処理されます。

**動かし方は 2 通りあります。**

| | 起動 | 必要なもの | 向き |
|---|---|---|---|
| **ローカル版** | `npm start` | Node 20 + ffmpeg | 自分用。ProRes の入出力ができる |
| **ブラウザ版** | 静的ホスティングに `web/` を置くだけ | 対応ブラウザだけ | **URL を渡して人に使ってもらう** |

中身は同じアプリで、起動したときに自動で切り替わります。
書き出しの速度はブラウザ版のほうが速いくらいです(→ [docs/spec.md](docs/spec.md) §13)。

## ローカル版

```bash
npm install
npm start
```

必要なもの: Node.js 20 以上 と ffmpeg(`brew install ffmpeg`)

`http://127.0.0.1:5178` が開きます。画面上部に ① 動画を入れる → ② コメントを入れる → ③ 書き出す
と出るので、その通りに進めれば終わります。

### 1. 動画を入れる

mp4 か mov を画面にドロップします。ブラウザが再生できない形式(ProRes など)は、
プレビュー用に自動で変換されます。**書き出しには元のファイルを使う**ので画質は落ちません。

### 2. コメントを入れる

一番早いのは**スプレッドシートからコピーして貼り付ける**方法です。貼った瞬間に取り込まれます。
本文だけの1列でもかまいません。

```
うぽつ
wwwww
ここすき
```

CSVファイルを読み込むこともできますし、`＋ 追加` で1件ずつ書くこともできます。

列を使う場合はこう書きます。見本は [samples/sample.csv](samples/sample.csv)。

| time | text | color | pos | size |
|---|---|---|---|---|
| 0:03 | うぽつ | | | |
| 0:12 | ここから本編 | yellow | ue | big |

- 必須は `text` だけ
- 列名は日本語も可(`時刻` `コメント` `色` `位置` `サイズ`)
- **本文にカンマや記号が入っていても大丈夫です**(`+10,000!?` `#tvtokyo` など)
- 時刻は `12` `12.5` `1:23` `0:01:23` のどれでもよい
- `color` は色名(`red` `赤` など)か `#RRGGBB`
- `pos` は `naka`(流れる) / `ue`(上固定) / `shita`(下固定)
- `size` は `small` / `medium` / `big`

### 3. 書き出す

左下の `書き出す` を押します。隣で出力の種類を選べます。

| 種類 | 内容 |
|---|---|
| **mp4 — 音声そのまま** | 動画にコメントを焼き込みます |
| **MOV / 連番PNG(背景透過)** | コメントだけ。編集ソフトで自分で重ねたいとき |

`output/` に、元のファイル名 + タイムスタンプで保存されます。

## 時刻を書かない ─ 自動配置

**時刻を空にした行は、動画全体に自動で散らばります。** コメント一覧の下の「時刻」バーで調整します。

```
時刻 [自動で散らす|手で指定]  区間全体に散らす▾  ゆらぎ ──●──  区間 0:00 〜 見切れないところまで▾
自動 50 件 — 毎秒 2.50 件 · 画面に常時 約 10.0 個 · 最後は 2:56
```

**入れた件数がどれくらいの密度になるか、その場で数字で出ます。** 迷ったらこれを見てください。

| 設定 | 内容 |
|---|---|
| 区間全体に散らす | 件数を区間いっぱいに広げます |
| 毎秒 N 件 | 密度を決めて先頭から詰めます |
| ゆらぎ | 間隔の不揃いさ。0 にすると完全な等間隔 |
| 区間 | コメントを出す範囲 |

### 最後のコメントが見切れるとき

コメントは4秒かけて画面を横断するので、既定のままだと**最後のほうのコメントは流れ切る前に動画が終わります**
(本家のニコニコ動画と同じ挙動です)。

全部を最後まで見せたい場合は、区間の終わりを **「見切れないところまで」** にしてください。
`動画の尺 − 横断秒数` で自動的に打ち切られ、流れる速さを変えると終端も追従します。

| 終わりの指定 | 内容 |
|---|---|
| 動画の最後まで(既定) | 最後のコメントは途中で切れます |
| **見切れないところまで** | 全部のコメントが流れ切ります |
| 時刻を指定 | 途中で切り上げます |

### 手で置いたものと混ぜる

時刻の左の **［自動］/［固定］** バッジを押すと切り替わります。時刻を書けば固定、空にすれば自動に戻ります。

全体の流れが決まったら **［時刻を確定］** を押すと、自動の行が全部その時刻で固定されます。
以降は普通のコメントとして細かく詰められます(元に戻すで取り消せます)。

#### どれくらい入れればいい?

```
画面上の同時表示数 ≒ 毎秒の件数 × 4
```

| 毎秒 | 20秒での総数 | 画面上 | 印象 |
|---|---|---|---|
| 1 | 20 | 約4 | 途切れないが寂しい |
| **2〜3** | **40〜60** | **8〜11** | **ほどよい** |
| 5 | 100 | 約19 | かなり密 |
| 10 | 200 | 上限40に当たる | 弾幕 |

上限(既定40)までなら**コメント同士はほぼ重なりません**。長いコメントが短いコメントに
追いつかないところまで見て行を割り当てているためです(→ [docs/spec.md](docs/spec.md) §4.1)。
もっと詰めたい場合は `詳細設定` で上限を上げられますが、画面には13行しかないので重なり始めます。

## アプリ上での編集

- 一覧の行はその場で編集できる。行をクリックするとその時刻にシーク
- 行頭のチェックボックスで選択し、**選択を削除** でまとめて消せる
  (Shift+クリックで範囲選択、ヘッダーのチェックで全選択)
- **全削除** は2段階。1回目で「もう一度で全削除」に変わり、3秒以内にもう一度押すと消える
- **＋ 現在位置に追加** で、いま止まっている位置にコメントを足せる
  (自動配置が有効なときは **＋ 末尾に追加** になり、時刻は自動で決まる)
- `Cmd+Z` / `Cmd+Shift+Z` で元に戻す・やり直す
- **CSV書出** で編集結果を同じ形式で保存できる(スプレッドシートに貼り戻せる)。
  自動配置の行は時刻を空で書き出すので、読み直しても自動のまま
- 編集内容はブラウザに自動保存されるので、閉じても続きから作業できる

画面右下の `キー操作` ボタンでも一覧できます。

## キーボード

| キー | 動作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` `→` | 1 コマ戻る / 進む |
| `Shift + ←` `→` | 5 秒戻る / 進む |
| `Cmd+Z` / `Cmd+Shift+Z` | 元に戻す / やり直す |
| `Cmd+A` | すべてのコメントを選択 |
| `Delete` / `Backspace` | 選択したコメントを削除 |
| `Esc` | 選択を解除 |

## 書き出し先を変える(ローカル版)

既定は `output/` です。変えたいときは `NICOCOME_OUTPUT` を指定します。

```bash
NICOCOME_OUTPUT=~/Movies npm start
```

## 表示の調整

右側のパネルで、文字の大きさ・太さ・フォント・縁取りの濃さ・流れる速さを変えられます。

`詳細設定` を開くと、フォントサイズや行数といった生の数値を直接いじれます。
既定値は**ニコニコ動画の実際の描画パラメータ**です(→ [docs/spec.md](docs/spec.md) §2)。

## ブラウザ版

**https://mmmmoeko.github.io/nicocomemaker/**

`web/` フォルダをそのまま静的ホスティングに上げるだけです。
このリポジトリでは `main` に push すると [GitHub Actions](.github/workflows/pages.yml) が自動で公開します。
**ビルド工程はありません。** `server/` `samples/` `output/` は要りません。

上げる前に手元で同じ状態を確かめられます。

```bash
npm run web
```

`http://127.0.0.1:5179` が API 無しで開くので、公開したときと同じ動きになります。

### ローカル版との違い

| | ローカル版 | ブラウザ版 |
|---|---|---|
| 入力できる動画 | なんでも(ProRes も自動変換) | ブラウザが再生できるもの(mp4 / H.264 など) |
| 合成 mp4 | ○ | ○ |
| コメントだけ(背景色つき mp4) | ○ | ○ |
| コメントだけ(背景透過) | ○ MOV / ProRes / 連番PNG | × |
| 保存先 | `output/` に直接 | ブラウザのダウンロード |

**対応ブラウザ**: Chrome / Edge / Safari 17+(WebCodecs の H.264 書き出しが要ります)。Firefox は非対応です。
